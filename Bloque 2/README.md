# Bloque 2

Ejercicios organizados por bloque y número.

```text
src/app/bloques/
└── bloque-2/
    ├── ejercicio-2.1/
    ├── ejercicio-2.2/    # Resaltado
    ├── ejercicio-2.3/
    ├── ejercicio-2.4/
    ├── ejercicio-2.5/    # Selector de cantidad (número por confirmar)
    ├── ejercicio-2.6/
    └── ejercicio-2.7/    # Catálogo y tarjetas de productos (en desarrollo)
```

Cada ejercicio guarda sus componentes, plantillas, estilos y pruebas en su carpeta. Las carpetas sin ejercicios hechos quedan reservadas.

Los demás bloques se encuentran en sus propias carpetas en la raíz del repositorio.

## Continuar trabajando

Desde la raíz del repositorio, entra en `Bloque 2`. Instala las dependencias una vez con `npm ci` y después usa `npm start`.

Ahora se muestra el selector de cantidad que estabas haciendo. El ejercicio 2.2 queda guardado en su carpeta para consultarlo.

La configuración de Angular y las dependencias de este proyecto están en la carpeta `Bloque 2`.

## Ejercicio 2.7

El proyecto completo del ejercicio 2.7 se guarda en `src/app/bloques/bloque-2/ejercicio-2.7`, con su propia configuración y dependencias. Para retomarlo, entra en esa carpeta y ejecuta `npm ci` y `npm start`. Consulta [CONTINUAR.md](src/app/bloques/bloque-2/ejercicio-2.7/CONTINUAR.md) para ver el estado pendiente de terminar.
