# Bloque 2 · Carril B · Ejercicio 2.2

Proyecto Angular `ProyectoDirectiva`: directiva `appResaltado` que aplica un color de fondo al pasar el ratón y lo elimina al salir. El color se recibe mediante una entrada de la directiva.

## Ejecutar

Desde esta carpeta:

```bash
npm ci
npm start
```

Abre `http://localhost:4200/`.

## Comandos

| Comando | Uso |
| --- | --- |
| `npm start` | Iniciar el servidor de desarrollo |
| `npm run build` | Compilar el proyecto en `dist/` |
| `npm test -- --watch=false` | Ejecutar las pruebas una vez |
| `npm run watch` | Compilar en desarrollo y observar los cambios |

## Archivos principales

- `src/app/app-resaltado.ts`: implementación de la directiva.
- `src/app/app.html`: ejemplos de uso.
- `src/app/app-resaltado.spec.ts`: prueba de la directiva.
