# Bloque 1

Proyecto Angular con los ejercicios del bloque 1, organizados por número.

```text
src/app/bloques/
└── bloque-1/
    ├── ejercicio-1.3/    # Tarjeta de producto (primer componente)
    ├── ejercicio-1.4/    # Ficha de producto (interpolación y property binding)
    ├── ejercicio-1.5/    # Alta rápida (event binding y ngModel)
    └── ejercicio-1.6/    # Cronómetro (ngOnInit / ngOnDestroy)
```

## Continuar trabajando

Desde la raíz del repositorio, entra en `Bloque 1`. Instala las dependencias una vez con `npm ci` y después usa `npm start`.

Ahora se muestran la alta rápida y el cronómetro; la tarjeta y la ficha de producto están comentadas en `src/app/app.html`.
