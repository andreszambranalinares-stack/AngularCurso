# Bloque 2 · Selector de cantidad

Ejercicio en curso de comunicación entre componentes con `@Input()` y `@Output()`.

- `ejercicio-selector-cantidad.ts` y `.html`: componente padre y recepción de la cantidad.
- `selector-cantidad/`: componente hijo con sus entradas, evento de salida, plantilla y prueba.

Abre `http://localhost:4200/bloque-2/selector-cantidad` después de ejecutar `npm start` desde la raíz. Este ejercicio comparte las dependencias del curso.

Se conserva la lógica del selector para continuar el ejercicio.
