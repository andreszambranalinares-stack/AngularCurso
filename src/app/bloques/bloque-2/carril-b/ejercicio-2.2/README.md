# Bloque 2 · Carril B · Ejercicio 2.2

La directiva `appResaltado` aplica un color de fondo al pasar el ratón y lo elimina al salir. El color se recibe mediante una entrada de la directiva.

- `app-resaltado.ts`: implementación original de la directiva.
- `app-resaltado.spec.ts`: pruebas con los colores rojo y verde y la salida del ratón.
- `ejercicio-2-2.ts` y `.html`: componente y ejemplos de uso.

Abre `http://localhost:4200/bloque-2/carril-b/ejercicio-2.2` después de ejecutar `npm start` desde la raíz. Este ejercicio comparte las dependencias del curso.
